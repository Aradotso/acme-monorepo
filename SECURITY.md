# Security Policy

## Supported versions

Security fixes are made against the latest version on the `main` branch.

## Responsible disclosure

Please do not report security vulnerabilities in a public issue or pull request.
We ask that you give us a reasonable opportunity to investigate and address a
report before making any information public.

### Contact

Use GitHub's private vulnerability reporting form for this repository:

<https://github.com/Aradotso/acme-monorepo/security/advisories/new>

When reporting a vulnerability, include the affected file or component, clear
steps to reproduce it, the potential impact, and any suggested mitigation.
Please avoid including secrets or personal data in the report.

We will acknowledge receipt through GitHub and coordinate disclosure timing
with the reporter after the issue has been investigated and addressed.
